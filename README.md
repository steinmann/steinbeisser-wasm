# Steinbeisser WASM

Browser UI and WebAssembly build for Steinbeisser.

## Layout

- `engine/` is the Rust crate that compiles to WebAssembly.
- `web/` is the editable frontend source.
- `dist/` is generated by `scripts/build.sh` and can be deleted at any time.
- `dist/pkg/` is generated by `wasm-bindgen`.

Edit files in `web/`, not `dist/`. The build script recreates `dist/` from `web/` and the compiled engine.

## Build and Serve

```bash
./scripts/build.sh
python3 ./scripts/serve.py dist
```

Then open `http://127.0.0.1:4173`.
